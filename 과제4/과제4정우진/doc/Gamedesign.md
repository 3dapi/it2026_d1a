## 1. 게임 제목

**Escape Mine**

---

## 2. 게임 개요

출구가 무너져 갇힌 광산에서, 한정된 산소를 아껴 가며 천장을 파고 올라가 탈출하는 **싱글 플레이 2D 아케이드 게임**이다.

| 항목 | 내용 |
| --- | --- |
| 장르 | 2D 아케이드 (브레이크아웃 계열) |
| 플랫폼 | Windows 데스크톱 (Visual Studio C# / glc2d) |
| 플레이 인원 | 1인 |
| 1회 플레이 타임 | 약 5분 목표 |
| 조작 장치 | 마우스 + 키보드 (Space / R / ESC) |

브레이크아웃(벽돌깨기) 계열의 반사 규칙을 기반으로 하되, 다음 세 가지를 차별점으로 둔다.

1. **Life(목숨)가 아닌 산소(시간)를 유일한 자원으로 사용한다.** 공을 놓쳐도 즉시 패배하지 않지만 산소가 계속 소모되므로, 플레이어는 "안전하게 여러 번"과 "빠르게 한 번"을 저울질하게 된다.
2. **곡괭이(바)의 방향 전환이 곧 강타 모드이다.** 가로 상태에서는 균형 잡힌 벡터로 넓게 파고, 세로 상태에서는 높은 y 벡터로 좁고 깊게 판다. 세로 상태에서는 공의 파괴력이 2배가 되는 대신 산소 소모가 커진다.
3. **돌의 내구도가 아니라 공의 파괴력을 소모하는 방식으로 판정한다.** 공은 파괴력이 남아 있는 한 여러 개의 돌을 연속으로 관통 파괴할 수 있다.

---

## 3. 게임 목적

산소를 모두 소진하기 전에 **최상단 행의 벽돌을 1개 이상 파괴**하여 광산을 탈출한다.

---

## 4. 조작 방법

| 입력 | 동작 |
| --- | --- |
| 마우스 이동 | 곡괭이의 x 좌표가 커서를 따라 이동 (y 좌표는 고정) |
| 마우스 좌클릭 | 곡괭이 휘두르기. 판정 범위 안에 공이 있으면 타격 |
| 마우스 우클릭 | 강타 모드 ON. 곡괭이가 세로로 전환 (재입력 시 수동 해제) |
| Space | 타이틀 화면에서 대기 화면으로 진입 |
| R | 결과 화면에서 타이틀 화면으로 복귀 (재시작) |
| ESC | 결과 화면에서 프로그램 종료 |

곡괭이의 가로/세로 방향은 강타 모드 상태와 연동되며, **별도의 방향 전환 입력은 없다.**

| 곡괭이 상태 | 전환 조건 |
| --- | --- |
| 가로 (일반) | 기본 상태. 강타 모드로 1회 타격한 직후 자동 복귀 |
| 세로 (강타) | 우클릭 시 활성화. 좌클릭으로 1회 타격하면 비활성화 |

## 5. 게임 규칙

### 5.1 기본 규칙

- 플레이어는 곡괭이(바)를 조작하여 공을 튕길 수 있다.
- 곡괭이로 타격한 공에는 **파괴력(Power)** 수치가 부여된다.
- 공이 돌에 접촉하면 해당 돌의 내구도만큼 파괴력이 소모되고, 돌의 내구도가 감소한다.
- 내구도가 0이 된 돌은 파괴되어 화면에서 제거된다.
- 파괴력이 남아 있으면 공은 반사되지 않고 계속 진행하여 다음 돌을 연속으로 타격한다.
- 파괴력이 0이 되면 공이 반사된다.
- 파괴력이 0인 공은 돌에 접촉해도 내구도를 감소시키지 않고 반사만 된다. 다시 곡괭이로 타격해야 파괴력을 얻는다.
- 시간이 지날수록 산소가 자동으로 감소하며, 곡괭이를 휘두르면 산소가 추가로 소모된다.

### 5.2 HP / Life 규칙

플레이어의 생존 자원은 **산소 하나뿐**이며, 공을 놓쳐도 목숨이 감소하지 않고 산소 소모라는 형태로만 손해가 발생한다. 즉 산소 게이지가 사실상 HP/Life의 역할을 겸한다.

### 5.3 파괴력 판정

| 타격 방식 | 부여 파괴력 |
| --- | --- |
| 가로 곡괭이 (일반) | 1 |
| 세로 곡괭이 (강타) | 2 |

판정 예시

| 상황 | 결과 |
| --- | --- |
| 파괴력 1 -> 암석(내구 1) | 암석 파괴, 파괴력 0, 반사 |
| 파괴력 1 -> 화강암(내구 2) | 화강암 내구 1로 감소, 파괴력 0, 반사 |
| 파괴력 2 -> 암석(내구 1) -> 암석(내구 1) | 암석 2개 연속 파괴, 파괴력 0, 반사 |
| 파괴력 2 -> 화강암(내구 2) | 화강암 파괴, 파괴력 0, 반사 |
| 파괴력 2 -> 산소통(공백) -> 암석(내구 1) | 산소 회복 후 암석 파괴, 파괴력 1 남음, 계속 진행 |

이 방식을 통해 강타 모드는 화강암 돌파뿐 아니라 **일반 암석 2개 연속 파괴**라는 용도를 함께 가지므로, 게임 전 구간에서 선택 가치를 유지한다.

### 5.4 곡괭이 방향에 따른 반사 규칙

| 방향 | 부여 벡터 | 파괴력 | 전술적 용도 |
| --- | --- | --- | --- |
| 가로 (Horizontal) | 균형 잡힌 abs(vx), abs(vy) | 1 | 넓게 파기. 초반 광범위 탐색 |
| 세로 (Vertical) | 높은 abs(vy), 낮은 abs(vx) | 2 | 좁고 깊게 파기. 특정 지점 집중 공략 |

- 곡괭이 중심에서 벗어난 위치로 타격할수록 x 성분이 커지도록 한다. 순수 반사(입사각 = 반사각)만 사용할 경우 궤적이 단조롭게 반복되므로, **타격 지점에 따른 각도 변조를 필수로 적용한다.**
- 세로 곡괭이가 단순 상위 호환이 되지 않도록, 세로 타격 시 x 성분을 충분히 낮게 억제하여 좁은 범위만 반복 공략하게 만든다. 초반에 세로만 사용하면 탐색 효율이 떨어지도록 하는 것이 밸런싱의 목표이다.

### 5.5 산소 규칙

아래 수치는 전부 **임시값**이다. 실제 플레이 테스트를 통해 목표 플레이 타임 5분에 맞춰 조정한다.

| 항목 | 임시값 | 비고 |
| --- | --- | --- |
| 최대 산소 | 100 | 게이지 10칸 = 칸당 10 |
| 자연 감소 | 0.25 / 초 | 임시값 |
| 일반 스윙 소모 | 1.0 / 회 | 임시값 |
| 강타 스윙 소모 | 2.5 / 회 | 임시값 |
| 산소통 회복량 | 최대치의 20% | 임시값 |

### 5.6 공 처리 규칙

- 공은 화면 좌 / 우 벽에서 반사된다.
- 플레이어가 좌클릭하지 않아 공이 바닥에 도달한 경우, 공은 바닥에서 반사되어 다시 상승한다. 목숨은 감소하지 않으나 그동안 산소가 계속 소모되므로 실질적인 손해가 된다.

### 5.7 강타 모드 규칙

- 우클릭으로 활성화한다. 곡괭이가 세로로 전환된다.
- 활성화 상태에서 좌클릭으로 1회 타격하면 자동으로 비활성화되고 가로 상태로 복귀한다.
- 헛스윙한 경우에도 1회 타격으로 간주하여 비활성화된다. *(부록 A-3 참조)*
- 활성화 상태에서 다시 우클릭하면 수동으로 해제할 수 있다.

### 6.1 승패 판정

| 결과 | 조건 |
| --- | --- |
| 승리 (탈출 성공) | 산소가 남은 상태에서 최상단 행의 벽돌을 1개 이상 파괴 |
| 패배 (질식) | 승리 조건을 충족하기 전에 산소가 0이 됨 |

### 6.2 점수 규칙

| --- | --- |
| 암석(일반 돌) 파괴 | 20점 |
| 화강암(단단한 돌) 파괴 | 40점 |
| 잔여 산소 보너스 | 잔여 산소 x 20점 (승리 시에만) |

- 결과 화면에 최종 점수와 클리어 시간을 표시하고, 세션 내 최고 점수를 갱신 표시한다.
- 임시값이므로 추후 수정될 수 있다.

## 7. 게임 시작 조건

화면 전환을 **타이틀 -> 대기 -> 플레이** 3단계로 구성한다.

| 단계 | 진입 조건 | 상태 |
| --- | --- | --- |
| 타이틀 화면 | 프로그램 실행 | 게임 제목 및 조작 안내 표시 |
| 대기 화면 | 타이틀에서 Space 입력 | 돌이 배치되고 공이 곡괭이 위에 정지한 상태로 대기. 산소는 감소하지 않음 |
| 플레이 | 대기 화면에서 좌클릭으로 곡괭이를 휘두름 | 공이 발사되고 산소 감소 시작 |

게임 시작 시 산소는 최대치로 초기화되고, 돌 필드가 배치된다. **재시작의 경우에도 동일한 초기화 절차를 거친다.**

---

## 8. 게임 종료 조건

종료를 두 단계로 구분한다.

**게임 오버 (플레이 종료)**

- 최상단 행 벽돌 1개 이상 파괴 -> 승리 화면으로 전환
- 산소 0 도달 -> 패배 화면으로 전환

**프로그램 종료**

- 결과 화면에서 ESC 키 입력 시 프로그램이 종료된다.
- 결과 화면에서 R 키 입력 시 타이틀 화면으로 복귀한다.

## 9. 플레이어 행동

| 행동 | 설명 |
| --- | --- |
| 이동 | 마우스 커서를 따라 곡괭이의 x 좌표가 갱신된다. y 좌표는 고정이다. |
| 타격 | 좌클릭으로 곡괭이를 휘두른다. 판정 범위 내에 공이 있으면 파괴력을 부여하여 반사시키고, 없으면 헛스윙이 되어 산소만 소모된다. |
| 강타 모드 전환 | 우클릭으로 곡괭이를 세로로 세운다. 파괴력이 2가 되고 공에 높은 y 벡터를 부여하지만, 산소 소모가 커지고 파는 범위가 좁아진다. |

## 10. 적 / 장애물 / 아이템 행동

이 게임에는 **능동적으로 움직이는 적이 없다.** 장애물과 아이템은 모두 정적으로 배치된다.

| 대상 | 분류 | 내구도 | 행동 |
| --- | --- | --- | --- |
| 암석 (일반 돌) | 장애물 | 1 | 파괴력 1 이상의 공에 접촉 시 파괴된다. |
| 화강암 (단단한 돌) | 장애물 | 2 | 파괴력 2가 필요하다. 파괴력 1로 접촉 시 내구도가 1 감소하며 균열 스프라이트로 변경된다. |
| 산소통 | 아이템 | 없음 (공백 칸) | 돌이 없는 빈 칸에 배치된다. 공이 접촉하면 산소를 회복시키며 파괴력을 소모하지 않는다. 따라서 공은 산소통을 통과하여 그 너머의 돌을 같은 파괴력으로 계속 타격할 수 있다. 획득 후 해당 칸에서 제거된다. |

- 모든 돌은 격자 형태로 배치되며 스스로 움직이지 않는다.
- 화강암과 산소통의 배치는 별도 알고리즘으로 결정한다. *(부록 A-2 참조)*
- 산소통은 공백 칸에 놓이므로, 플레이어에게는 "이미 파놓은 통로 안의 보상"으로 보이게 된다.

## 11. 게임 화면 구성

해상도는 **1280 x 720**을 기준으로 한다. (ScreenX = 1280, ScreenY = 720)

```
+--------------------------------------------+  y = 0
|  [벽돌 영역 - 화면에 보이는 부분]            |
|  암석 / 화강암 / 산소통 격자 배치            |
|  ※ 실제 필드는 화면 위쪽으로 더 연장됨       |
+--------------------------------------------+  y = ScreenY / 5   (144)
|                                          |
|            [공 이동 영역]                  |
|             (배경: 흙바닥)                 |
|                                          |
|               ===  곡괭이                  |  y = ScreenY * 5/6 (600)
|                                          |
+--------------------------------------------+
|  산소 게이지 ■■■■■■□□□□    점수: 000       |
+--------------------------------------------+  y = ScreenY      (720)
```

| 요소 | 위치 | 비고 |
| --- | --- | --- |
| 벽돌 영역 (표시) | y: 0 ~ ScreenY/5 | 화면에 출력되는 범위 |
| 벽돌 필드 (실제) | 화면 상단 밖으로 연장 | 총 행 수는 플레이 테스트로 확정 *(부록 A-1)* |
| 공 이동 영역 | y: ScreenY/5 ~ 하단 UI 위 | 배경은 흙바닥 |
| 곡괭이 초기 위치 | (ScreenX/2, ScreenY x 5/6) | y 고정, x만 이동 |
| 산소 게이지 | 화면 하단 좌측, 10칸 직사각형 | 칸당 최대치의 10% |
| 점수 표시 | 화면 하단 우측 | |

## 12. 게임 진행 흐름

```
[타이틀 화면]
     |  Space
     v
[대기 화면] --- 돌 배치 / 공 정지 / 산소 감소 없음
     |  좌클릭 (곡괭이 휘두르기)
     v
[게임 시작] --- 산소 감소 시작 / 공 발사
     |
     v
[초반] 산소 여유 --- 가로 곡괭이로 광범위하게 돌 파괴
     |
     v
[중반] 산소 감소 --- 산소통 위치 파악 후 우선 확보
     |
     v
[후반] 산소 부족 --- 가장 많이 판 지점을 세로 곡괭이(강타)로 집중 공략
     |
     +--- 최상단 벽돌 파괴 ----> [승리 화면]
     |                                |
     +--- 산소 0 도달 --------> [패배 화면]
                                      |
                          +-----------+-----------+
                        R |                       | ESC
                          v                       v
                   [타이틀 화면]           [프로그램 종료]
```

## 16. 제작 범위 (완성 가능성)

과제 기간 내 완성을 보장하기 위해 다음과 같이 우선순위를 구분한다.

### 필수 구현 (MVP)

- 곡괭이 이동 및 좌클릭 스윙 판정
- 공의 이동, 벽 / 돌 / 곡괭이 반사
- 파괴력 기반 관통 판정
- 돌 격자 배치, 내구도 처리, 파괴
- 강타 모드 (세로 곡괭이) 전환 및 1회 소모
- 산소 자연 감소 및 스윙 소모
- 승리 / 패배 판정
- 타이틀 / 대기 / 플레이 / 결과 화면 전환
- 산소 게이지 UI
- 이미지 및 사운드 적용
- 산소통 아이템
- 화강암 및 균열 상태

### 확장 구현 (여유 시)

- 화강암 / 산소통 배치 알고리즘 고도화
- 점수 및 최고 점수 표시
- 스윙 이펙트 및 파티클
- 벽돌 필드 스크롤
