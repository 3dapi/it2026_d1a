# Ten Planets 게임 기획서

## 1. 게임 제목

Ten Planets


## 2. 게임 장르

2D 퍼즐 게임


## 3. 게임 설명

Ten Planets는 화면에 배치된 여러 행성을
마우스로 드래그하여 선택하는 퍼즐 게임이다.

각 행성에는 1부터 9까지의 숫자가 적혀 있다.

플레이어는 여러 행성을 선택하여
숫자의 합이 10이 되도록 만들어야 한다.

선택한 행성 숫자의 합이 10이면
해당 행성들이 사라지고 점수를 얻는다.

제한 시간 2분 동안 최대한 많은 행성을 없애
높은 점수를 얻는 것이 목표이다.


## 4. 게임 목표

제한 시간 2분 동안
숫자의 합이 10이 되는 행성들을 찾아 제거한다.

행성 하나를 제거할 때마다
점수를 1점 얻는다.

시간이 모두 지나면 게임이 종료되며
최종 점수를 확인할 수 있다.


## 5. 게임 규칙

1. 게임을 시작하면 행성 170개가 배치된다.

2. 행성은 가로 17칸, 세로 10칸으로 배치된다.

3. 각각의 행성에는 1부터 9까지의 숫자가 랜덤으로 들어간다.

4. 플레이어는 마우스를 드래그하여 여러 행성을 선택할 수 있다.

5. 선택된 행성들의 숫자를 모두 더한다.

6. 숫자의 합이 10이면 선택한 행성들이 사라진다.

7. 없어진 행성의 자리는 빈칸으로 남는다.

8. 행성 하나를 없앨 때마다 점수가 1점 증가한다.

9. 제한 시간은 2분이다.

10. 시간이 0초가 되면 게임이 종료된다.


## 6. 조작 방법

마우스 이동
- 버튼을 선택하거나 행성을 선택할 때 사용한다.

마우스 왼쪽 클릭
- START 버튼을 누른다.
- RETRY 버튼을 누른다.

마우스 왼쪽 버튼 드래그
- 여러 행성을 선택한다.

ESC
- 게임을 종료한다.


## 7. 화면 구성

### 시작 화면

게임을 실행하면 처음으로 보이는 화면이다.

배경 이미지와 START 버튼이 표시된다.

START 버튼에 마우스를 올리면
버튼 이미지가 변경된다.

START 버튼을 클릭하면 게임 화면으로 이동한다.


### 게임 화면

게임의 실제 플레이 화면이다.

화면에 170개의 행성이 나타난다.

행성 위에는 각각 1부터 9까지의 숫자가 표시되어 있다.

마우스로 행성들을 드래그하여 선택할 수 있다.

화면에는 현재 점수와 남은 시간이 표시된다.


### 게임 종료 화면

제한 시간이 모두 지나면 나타나는 화면이다.

TIME OVER 배경을 표시하고
게임에서 획득한 SCORE를 보여준다.

RETRY를 누르면 게임을 다시 시작할 수 있다.

## 9. 현재 구현한 기능

현재까지 다음 기능을 구현하였다.

- 시작 화면 출력
- START 버튼 출력
- START 버튼 마우스 Hover
- START 클릭 시 게임 시작
- 게임 화면 배경 출력

- 17 × 10 행성 배치
- 행성 숫자 랜덤 생성
- 마우스 드래그 기능
- 선택된 행성 판정
- 선택된 숫자의 합 계산
- 합이 10인지 확인
- 합이 10이면 행성 삭제
- 점수 증가
- SCORE 화면 표시
- 2분 타이머
- TIME OVER 화면
- RETRY 기능
- ESC 게임 종료
