# 26031001_최세아_객체지향프로그래밍_게임제작

# 뱀게임

# 게임 개요
 - 플레이어가 격자 화면 속 뱀을 조작해 음식을 먹으며 크기를 키워나가는 게임
 
#패배 조건
 1. 뱀의 머리가 화면 외각 벽에 충돌할 경우
 2. 벰의 머리가 자신의 몸통 좌표에 충돌할 경우
 
#승리 조건
 - 별도의 엔딩 없이 패배 전까지 진행되는 무한 스코어링 방식
 
# 게임 목적 
 - 자신의 몸통이나 벽에 부딪히지 않고, 
  화면에 나타나는 음식을 계속 먹어서 뱀의 몸길이를 최대로 키우며 높은 점수를 기록
 
# 조작방법
 - WASD 이동 
 - 현재 진행 방향의 역방향으로 즉시 전환 불가한 조작 제한을 둠
 
# 핵심시스템
 1. 격자 및 위치 좌표
  - 화면을 N x M 크키의 격자 칸 분활
  - 뱀의 머리, 몸통, 음식의 위치를 격가 좌표로 다룸
  
 2. 충돌 감지 
  - 벽 충돌 : 뱀 머리의 좌표가 격자 범위를 벗어났는지 
  - 자충돌 : 뱀 머리 좌표와 몸통 좌표 목록에 포함되어 있는지
  - 음식 충돌 : 머리 좌표와 음식 위치가 일치한지 
  
  3. 뱀 좌표 업데이트 
   - 뱀의 머리와 몸통을 하나씩 늘리고 제거하며 이동을 하는 것
   
  4. 게임 루프 및 사용자 입력
   - WASD를 확인하여 다음 이동 방향을 결정, 누르지 않았다면 이동방향 유지
   - 음식이 먹을 때마다 실시간으로 다른 위치에 나타남
   - 실패시  실패판정 > 게임 정지 > 데이터 초기화 > 루프 재시작
