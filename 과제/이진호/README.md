# GameProject

- 게임 제목: 최종병기: 활
- 게임 장르: 2D 사이드뷰 아레나 액션

## 게임 방식

- 한 화면으로 구성된 아레나에서 계속 등장하는 적을 활로 처치한다.
- 플레이어는 좌우 이동, 점프와 대시를 이용해 적의 공격을 피한다.
- 발사한 기본 화살은 자동으로 돌아오지 않으며 직접 이동하여 회수해야 한다.
- 생존 시간이 길어질수록 아레나에 등장하는 적의 수가 증가한다.

## 게임 목표

- 계속해서 등장하는 적을 처치하며 최대한 오래 생존하는 것이 목표다.
- 플레이어의 체력이 0이 되면 게임이 종료된다.
- 게임 종료 시 최종 처치 수와 생존 시간을 기록한다.

## 게임 조작

- A, D: 좌우 이동
- Space: 점프
- Shift: 대시
- 마우스 이동: 활 조준
- 마우스 왼쪽 버튼: 기본 화살 발사
- 마우스 오른쪽 버튼: 특수 화살 발사

## 게임 규칙

- 플레이어는 체력 3칸과 기본 화살 1발을 가지고 시작한다.
- 적이나 적의 공격에 맞으면 체력이 1칸 감소한다.
- 피격 후에는 약 1초 동안 무적 상태가 된다.
- 대시 중에는 짧은 무적 판정이 적용된다.
- 공중 대시는 착지하기 전까지 한 번만 사용할 수 있다.
- 적의 능력치와 공격 패턴은 시간이 지나도 강화되지 않는다.

## 화살 획득

- 일정 수의 적을 처치하면 새로운 기본 화살이 아레나에 등장한다.
- 새로운 기본 화살을 획득하면 사용할 수 있는 화살의 수가 영구적으로 증가한다.
- 기본 화살을 획득할 때마다 다음 화살에 필요한 처치 수가 크게 증가한다.
- 적 처치 시 낮은 확률로 특수 능력이 있는 일회용 화살이 등장한다.
- 일회용 특수 화살은 한 번 발사하면 소멸하며 회수할 수 없다.

## 게임 화면 구성

- 한 화면 크기의 사이드뷰 아레나
- 이동과 점프가 가능한 지면 및 발판
- 플레이어의 체력 표시
- 현재 처치 수와 생존 시간 표시
- 보유 중인 기본 화살과 특수 화살 표시

## 게임 진행 흐름

게임 시작 → 적 처치 → 기본 화살 회수 → 추가 화살 획득 → 적의 수 증가 → 플레이어 체력 소진 → 최종 기록 출력
