### 게임 제목
- **왁뿌수기**

### 개요
- 지뢰 찾기를 기반으로 한 ASMR 힐링 게임.
- 필드에 배치된 목표 타일을 피하면서 모든 타일을 부순다.
- 타일이 부서지는 소리와 시각적 효과를 통해 반복적 쾌감 제공.

### 목적
- 숨어 있는 목표를 피하면서 화면의 파괴 가능한 타일을 모두 부수는 것.

### 조작 방법
- 마우스 좌클릭: 칸 부수기
- ESC: 메뉴 열기

### 규칙
- 필드는 여러 개의 정사각형 칸으로 구성된다.
- 각 칸에는 일반 타일 또는 목표 타일이 배치된다.
- 칸을 클릭하면 해당 칸이 열린다.
- 목표 타일을 클릭하면 게임에 불이익 발생.
- 목표 타일을 모두 피하면서 모든 일반 타일을 부수면 스테이지를 클리어한다.

### 점수/ 승부 규칙
- 싱글 플레이 게임으로 구성.
- 남은 타일 수에 따라 진행도 표시.
- 목표 타일을 터트리지 않고 클리어하면 성공.
- 목표 타일을 클릭하면 점수가 감소하고 콤보가 초기화된다.
 
### 시작 조건
- 게임 시작 시 필드와 목표 타일의 위치가 무작위로 생성된다.
- 플레이어는 닫힌 타일만 존재하는 상태에서 게임을 시작한다.

### 종료 조건
- 모든 일반 타일을 부수면 스테이지 클리어.
- 목표 타일을 일정 횟수 이상 터트리면 게임 오버.

### 플레이어 행동
- 칸 클릭
- 목표로 예상되는 칸을 피해서 타일 부수기

### 적/ 장애물/ 아이템 등의 행동
- 목표 타일
  - 일반 타일과 구분되지 않는 상태로 필드에 배치.
  - 클릭하면 폭발.
  - 폭발 시 효과음과 함께 화면 효과 발생.
  - 플레이어의 점수와 콤보에 불이익을 준다.
- 보너스 타일
  - 부수면 일반 타일보다 큰 점수를 획득.
  - 특별한 파괴 효과음 재생.

### 화면 구성
- 상단
  - 현재 점수
  - 남은 일반 타일/ 목표 타일 수
  - 콤보
- 중앙
  - 게임 필드
- 하단
- 
- 메뉴
  - 게임 재시작
  - 사운드 설정
  - 메인 메뉴로 돌아가기
  - 게임 종료

### 진행 흐름
1. 게임 시작
2. 필드 생성
3. 플레이어가 타일 클릭
4. 반복
5. 점수 및 기록 확인
6. 다음 스테이지 진행
