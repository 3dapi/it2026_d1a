# 곡괭이 조작 데모

`BrickOut/BrickOut.sln`을 Visual Studio에서 열고 실행합니다.
프로젝트 target은 기존 `net9.0-windows7.0`을 유지하므로 실행에는 .NET 9 Desktop Runtime이 필요합니다.

실행하면 `Robby.png`를 배경으로 한 메인 화면이 나타납니다.
좌클릭 또는 Space를 누르면 바로 게임 조작 데모로 전환되고 동굴 ambience가 시작됩니다.
전환에 사용한 클릭은 곡괭이 스윙으로 처리하지 않습니다. 버튼을 놓았다가 다시 클릭하면 스윙합니다.
메인 화면에서는 곡괭이 조작과 F1~F5 사운드 미리듣기를 처리하지 않습니다.

| 입력 | 동작 |
| --- | --- |
| 마우스 이동 | 곡괭이 x 이동, y 고정, 화면 가장자리 제한 |
| 좌클릭 | 0.28초 스윙 animation + 일반/강타 효과음 |
| 우클릭 | 기본 자세 ↔ I자 강타 자세 전환 + 금속 전환음 |
| M | 효과음 ON/OFF |
| F1 | 돌 파괴음 미리듣기 |
| F2 | 공 반사음 미리듣기 |
| F3 | 산소 회복음 미리듣기 + 저산소 미리보기 해제 |
| F4 | 저산소 20% / 정상 100% 미리보기 전환 |
| F5 | 승리 박수 미리듣기 |

일반 자세는 기존 강타의 회전 각도(-45도)를 사용합니다. 새 강타는 `Pickaxe_Strong.png`의 수직 I자 모습으로 위로 들어 올리며, 헛스윙을 포함해 스윙 1회로 소모되고 animation 종료 시 일반 자세로 복귀합니다.
스윙 중 추가 클릭 및 모드 전환은 무시합니다. 누르고 있기만 해서는 연속 스윙하지 않습니다.
창이 비활성 상태일 때 조작을 처리하지 않습니다. 오디오 출력 장치가 없으면 무음으로 실행합니다.

현재 범위는 메인→게임 화면 전환, 이미지 배치와 곡괭이 조작입니다. 공 타격 판정, Power, 산소 소모, 돌 파괴, 승패 및 결과 화면 전환은 아직 구현하지 않았습니다.
곡괭이 상태는 `Pickaxe.cs`, 입력/렌더링/오디오 연결은 `GameMain.cs`에서 관리합니다.
사운드 로딩/재생/음소거는 `GameAudio.cs`, 저산소 간격은 `OxygenBreathTimer.cs`에서 관리합니다.
오디오 출처와 변환 내역은 `BrickOut/resource/sound/CREDITS.md`에 있습니다.
이미지와 사운드는 build/publish 출력에 자동 복사됩니다.

## 수동 확인

실행 직후 메인 화면에서 좌클릭 / Space를 각각 확인합니다. 좌클릭으로 진입한 뒤 누른 상태를 유지해도 스윙하지 않고, 다시 클릭할 때만 스윙해야 합니다.

1. 좌우 끝으로 이동하여 곡괭이가 화면 안에 머무는지 확인합니다.
2. 좌클릭을 누르고 있어도 한 번만 스윙하는지 확인합니다.
3. 우클릭 두 번으로 기본/I자 강타 자세가 전환되는지 확인합니다.
4. 강타 자세에서 좌클릭 후 기본 자세로 복귀하고 강타 효과음이 나는지 확인합니다.
5. M으로 무음 전환 후에도 스윙과 자세 전환이 되는지 확인합니다.
6. 창 크기 변경 및 Alt+Enter 후에도 곡괭이가 커서의 x 위치를 따르는지 확인합니다.
7. 실행 중 동굴 ambience가 반복되는지, M 및 다른 창으로 전환 시 멈추는지 확인합니다.
8. F4로 저산소를 켜면 5초 후부터 5초마다 약 3.17초 호흡이 재생되는지 확인합니다.
9. F3 또는 F4로 정상 상태로 돌아오면 호흡이 멈추는지 확인합니다.
10. 음소거 해제/창 복귀/저산소 재진입 시 5초를 새로 세며 밀린 호흡을 몰아서 재생하지 않는지 확인합니다.

## 실제 게임 이벤트 연결

`GameAudio.Update`에 실제 산소 비율(0~1), Play 상태 여부, 창 활성 여부를 전달하면 됩니다.
산소 비율이 0 초과 0.2 이하일 때만 호흡 timer가 진행됩니다. 산소 0 / 정상 회복 / Play 종료 시 반복을 중지합니다.
현재 데모는 F4의 모의 산소 비율을 전달하며 실제 산소 소모는 없습니다.
돌 파괴에는 `GameSound.RockBreak`, 반사에는 `GameSound.Bounce`, 회복에는 `GameSound.Oxygen`, 승리에는 `GameSound.Cheer`를 재생합니다.
결과 화면 진입 시 먼저 `Update`에 Play 종료를 알린 뒤 승리 효과음을 1회 호출합니다. 동굴/호흡 반복은 종료되고 승리 효과음은 재생할 수 있습니다.
현재 F1/F2/F3/F5는 미리듣기이며 돌 파괴/승패 시스템을 구현한 것은 아닙니다.
