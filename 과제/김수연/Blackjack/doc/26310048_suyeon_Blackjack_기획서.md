# 2차 과제 게임 기획서

## 게임 제목

- Light Blackjack
- 장르 : 카드 게임

---

## 게임 개요

- 블랙잭의 규칙을 간단하게 만든 카드게임

- 플레이어와 딜러가 카드를 받아 숫자의 합을 21에 가깝게 만듦

- 플레이어는 Hit 또는 Stand를 선택하여 게임을 진행

- 최종 카드 합계를 비교하여 Win / Lose / Draw를 결정

---

## 게임 목적

- 카드 합계가 21을 넘지 않도록 조절

- 딜러보다 21에 가까운 숫자를 만드는 것이 목표

- 여러 판을 진행하며 승리 횟수를 기록

---

## 조작 방법

- Game Start : 게임 시작

- Hit : 카드 1장 추가

- Stand : 현재 카드로 승부

- ReStart : 새로운 게임 시작

- Exit Game : 게임 종료

> 모든 조작은 마우스 클릭으로 진행

---

## 게임 규칙

### 사용 카드

- A, J, Q, K를 제외한 2 ~ 10 카드만 사용

- Spade, Heart, Diamond, Club 4가지 문양 사용

- 카드에 적힌 숫자를 그대로 점수로 계산

- 같은 판에서 이미 사용한 카드는 다시 나오지 않음

### 진행 규칙

- 게임 시작 시 플레이어와 딜러가 카드 1장씩 받음

- 플레이어는 자신의 카드를 확인할 수 있음

- 딜러의 카드는 승부 전까지 공개하지 않음

- 플레이어는 Hit 또는 Stand를 선택

- Hit 선택 시 카드 1장을 추가로 받음

- 합계가 21을 넘지 않으면 계속 Hit 또는 Stand 선택 가능

- 합계가 21을 초과하면 Bust로 패배

- 합계가 정확히 21이면 승리

- Stand 선택 시 플레이어의 카드 추가를 종료하고 딜러 차례로 진행

### 딜러 규칙

- 플레이어가 Stand를 선택하면 딜러의 카드를 공개

- 딜러는 합계가 18 미만이면 카드를 추가로 받음

- 합계가 18 이상이면 더 이상 카드를 받지 않음

- 합계가 21을 초과하면 Bust

### 승부 규칙

- 21을 초과하지 않은 상태에서 더 높은 합계를 가진 쪽이 승리

- 플레이어가 21을 초과하면 패배

- 딜러가 21을 초과하면 플레이어 승리

- 최종 합계가 같으면 Draw

## 게임 화면 구성

### Start Scene

- 게임 제목

- Game Start

- Exit Game 버튼

### Play Scene

- 상단 : Dealer 카드

- 중앙 : 게임 상태 / 결과 메시지

- 하단 : Player 카드와 현재 합계

- Hit / Stand 버튼

- Win / Lose / Draw 기록

### Result

- Win / Lose / Draw / Bust 결과 표시

- ReStart 버튼 표시

---

## 게임 진행 흐름

Game Start

→ 플레이어 / 딜러 카드 1장 지급

→ 플레이어 Hit 또는 Stand 선택

---

- Hit

→ 카드 추가

→ 합계 확인

→ 21 초과 시 Lose

→ 21이면 Win

→ 그 외에는 계속 진행

---

- Stand

→ 딜러 카드 공개

→ 딜러 자동 진행

→ 최종 합계 비교

→ Win / Lose / Draw 표시

→ ReStart

---

## 주요 게임 객체 목록

- Player : 플레이어 카드와 합계 관리

- Dealer : 딜러 카드와 행동 관리

- Card : 카드 숫자, 문양, 이미지 정보

- Deck : 카드 목록과 카드 지급 관리

- GameManager : 게임 진행 및 승패 관리

- GameButton : Start, Hit, Stand 등의 버튼

- RecordSystem : Win / Lose / Draw 기록 관리
