## 🕹️ 1주차 조작 방법 [미확정 - 테라리아 기본 조작 참고]
> ※ 현재 테라리아의 기본 2D 이동 및 저격 소총 조준경(우클릭 시야 확장) 조작 방식을 참고하여 1차 구현한 상태이며, 추후 피드백에 따라 변경될 수 있습니다.

- **A / D 키**: 좌 / 우 이동
- **W / Space 키**: 점프
- **S / Ctrl 키**: 엎드리기
- **마우스 이동**: 총구 조준선 회전
- **마우스 우클릭 (유지)**: 저격 스코프 시야 확장 (테라리아 조준경 조작 참고)
- **Shift 키 (유지)**: 호흡 참기 (조준선 흔들림 억제)
- **마우스 좌클릭**: 사격 (탄도학 중력 낙차 및 바람 반영)
