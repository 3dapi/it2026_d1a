# 러시안 룰렛 게임 기획서

## 1. 게임 개요

| 항목 | 내용 |
| --------- | ------------ |
| 게임명 | 러시안 룰렛 |
| 장르 | 확률 기반 심리 게임  |
| 예상 플레이 시간 | 3~5분 |

## 2. 기획 의도

플레이어와 적이 하나의 리볼버를 사용해 대결하며, 최대한 많은 적을 처치하고 상금을 획득하는 간단한 확률 게임을 제작한다.

플레이어는 자신의 차례마다 자신과 적 중 누구에게 사격할지 선택할 수 있다. 자신에게 사격해 생존하면 보너스와 추가 행동 기회를 얻지만, 총알이 발사되면 즉시 사망한다. 적에게 사격하면 자신이 즉시 사망할 위험은 없지만, 빈 약실이 나오면 적에게 차례를 넘겨주게 된다.

적을 처치한 후에는 다음 적에게 계속 도전하거나 지금까지 쌓은 상금을 받고 게임을 종료할 수 있다. 이를 통해 한 번의 대결 안에서는 사격 대상에 대한 선택을, 대결이 끝난 뒤에는 도전을 계속할지에 대한 선택을 제공한다.

## 3. 핵심 재미

> 남은 약실을 바탕으로 누구에게 사격할지 판단하고, 적을 처치한 뒤에는 다음 도전을 계속할지 상금을 확보할지 결정한다.

### 사격 대상 선택

* 자신에게 사격하면 즉시 사망할 위험이 있다.
* 자신에게 사격해 생존하면 보너스 상금을 받고 차례를 유지한다.
* 적에게 사격하면 자신이 즉시 사망할 위험은 없다.
* 적에게 사격했을 때 빈 약실이면 보상 없이 적에게 차례가 넘어간다.
* 빈 약실이 나올 때마다 남은 약실 수가 줄어들어 총알이 발사될 확률이 높아진다.
* 플레이어는 남은 약실을 확인하며 자신과 적 중 누구에게 사격할지 판단한다.

### 다음 도전 선택

* 적을 처치할 때마다 연속 승리 횟수와 획득 예정 상금이 증가한다.
* 다음 적에게 계속 도전할수록 더 많은 상금을 얻을 수 있다.
* 플레이어가 사망하면 현재 게임에서 쌓은 획득 예정 상금을 모두 잃는다.
* 플레이어는 적을 처치한 뒤 다음 적에게 도전하거나 상금을 받고 종료할 수 있다.
* 마지막 적이나 최대 연승 제한 없이 계속해서 기록에 도전할 수 있다.

## 4. 게임 목표

* 플레이어는 자신이 사망하기 전에 최대한 많은 적을 처치해야 한다.
* 플레이어는 자신의 차례에 자신 또는 적에게 사격할 수 있다.
* 자신에게 사격해 생존하면 도전 보너스를 획득한다.
* 적을 처치하면 연속 승리 횟수와 획득 예정 상금이 증가한다.
* 적을 처치한 후에는 다음 적에게 도전하거나 상금을 받고 게임을 종료할 수 있다.
* 최종 승리 조건은 존재하지 않으며, 최대한 높은 연속 승리와 상금을 기록하는 것이 목표다.
* 플레이어가 사망하거나 상금 수령을 선택하면 게임이 종료된다.

## 5. 기본 설정값

아래 수치는 초기 설정값이며, 실제 플레이 테스트 결과에 따라 변경할 수 있다.

| 항목 | 설정값 | 설명 |
| ------------ | ---- | ---------------------- |
| 전체 약실 수 | 6개 | 리볼버에 존재하는 전체 약실 수 |
| 총알 수 | 1개 | 매 대결에서 사용하는 총알 수 |
| 자신 사격 생존 보너스 | 50원 | 자신에게 사격해 생존했을 때 얻는 상금 |
| 첫 번째 적 처치 보상 | 100원 | 첫 번째 적을 처치했을 때 얻는 상금 |
| 처치 보상 증가량 | 100원 | 적을 추가로 처치할 때마다 증가하는 보상 |
| 최대 적 수 | 제한 없음 | 플레이어가 생존하는 동안 계속 등장 |
| 플레이어 시작 순서 | 첫 번째 | 새로운 적과 대결할 때 플레이어부터 시작 |

### 남은 약실에 따른 총알 확률

빈 약실이 나올 때마다 남은 약실 수가 감소하므로 다음 사격에서 총알이 발사될 확률이 높아진다.

| 남은 약실 | 총알이 발사될 확률 |
| ---- | --------- |
| 6개 | 1/6 |
| 5개 | 1/5 |
| 4개 | 1/4 |
| 3개 | 1/3 |
| 2개 | 1/2 |
| 1개 | 1/1 |

플레이어에게는 현재 남은 약실 수와 총알 수를 공개한다. 단, 총알이 들어 있는 정확한 약실의 위치는 공개하지 않는다.

### 적 처치 보상

적을 연속으로 처치할수록 해당 적을 처치했을 때 얻는 보상이 100원씩 증가한다.

| 처치한 적 | 해당 적 처치 보상 | 누적 처치 보상 |
| ---- | --------- | ------- |
| 1명 | 100원 | 100원 |
| 2명 | 200원 | 300원 |
| 3명 | 300원 | 600원 |
| 4명 | 400원 | 1,000원 |
| 5명 | 500원 | 1,500원 |

자신에게 사격해 생존하여 받은 도전 보너스는 누적 처치 보상과 별도로 획득 예정 상금에 더한다.

## 6. 게임 규칙

### 6.1 게임 시작

1. 플레이어는 게임 시작 또는 게임 종료를 선택한다.
2. 게임 시작을 선택하면 연속 승리 횟수와 획득 예정 상금을 0으로 초기화한다.
3. 첫 번째 적이 등장하고 새로운 리볼버를 준비한다.
4. 플레이어가 먼저 행동하며 대결을 시작한다.

### 6.2 리볼버 준비

1. 리볼버는 총 6개의 약실을 가진다.
2. 리볼버에는 총알 1개가 들어간다.
3. 게임은 1부터 6 사이의 무작위 숫자 하나를 총알이 들어 있는 약실로 결정한다.
4. 현재 약실은 1번부터 시작한다.
5. 방아쇠를 당길 때 현재 약실과 총알이 들어 있는 약실을 비교한다.
6. 빈 약실이면 현재 약실이 한 칸 이동한다.
7. 총알이 발사되면 사격 대상이 사망하고 해당 대결이 종료된다.
8. 새로운 적이 등장할 때마다 총알의 위치와 현재 약실을 다시 설정한다.

### 6.3 플레이어 차례

플레이어는 자신의 차례에 다음 행동 중 하나를 선택한다.

1. 자신에게 사격한다.
2. 적에게 사격한다.

플레이어가 선택하기 전에 현재 남은 약실 수와 총알 수를 출력한다.

### 6.4 자신에게 사격

플레이어가 자신에게 사격하면 다음과 같이 처리한다.

#### 빈 약실인 경우

* 플레이어가 생존한다.
* 획득 예정 상금에 도전 보너스 50원을 추가한다.
* 현재 약실을 한 칸 이동한다.
* 플레이어의 차례가 유지된다.
* 남은 약실 정보를 다시 출력하고 사격 대상을 선택한다.

#### 총알이 발사된 경우

* 플레이어가 즉시 사망한다.
* 현재 게임에서 쌓은 획득 예정 상금을 모두 잃는다.
* 연속 승리 횟수와 잃은 상금을 최종 기록으로 출력한다.
* 게임을 종료한다.

### 6.5 적에게 사격

플레이어가 적에게 사격하면 다음과 같이 처리한다.

#### 빈 약실인 경우

* 적이 생존한다.
* 도전 보너스는 지급되지 않는다.
* 현재 약실을 한 칸 이동한다.
* 플레이어가 차례를 잃고 적의 차례로 넘어간다.

#### 총알이 발사된 경우

* 적이 사망한다.
* 플레이어의 연속 승리 횟수가 1 증가한다.
* 현재 연속 승리 횟수에 따른 처치 보상을 획득한다.
* 플레이어는 다음 적에게 도전하거나 상금을 받을 수 있다.

### 6.6 적 차례

1. 적은 항상 플레이어에게 사격한다.
2. 적이 사격하기 전에 현재 남은 약실 수와 총알 수를 출력한다.

#### 빈 약실인 경우

* 플레이어가 생존한다.
* 현재 약실을 한 칸 이동한다.
* 플레이어에게 차례가 넘어간다.
* 플레이어는 자신과 적 중 사격 대상을 다시 선택한다.

#### 총알이 발사된 경우

* 플레이어가 즉시 사망한다.
* 현재 게임에서 쌓은 획득 예정 상금을 모두 잃는다.
* 연속 승리 횟수와 잃은 상금을 최종 기록으로 출력한다.
* 게임을 종료한다.

### 6.7 적 처치

적을 처치하면 다음과 같이 처리한다.

* 연속 승리 횟수가 1 증가한다.
* 현재 연속 승리 횟수에 따라 처치 보상을 계산한다.
* 계산된 처치 보상을 획득 예정 상금에 더한다.
* 현재 연속 승리 횟수와 획득 예정 상금을 출력한다.
* 플레이어는 다음 적에게 도전하거나 상금을 받을 수 있다.

처치 보상은 다음과 같이 계산한다.

```text
처치 보상 = 현재 연속 승리 횟수 × 100원
```

예를 들어 세 번째 적을 처치하면 300원을 추가로 획득한다.

세 명의 적을 처치하여 얻은 누적 처치 보상은 600원이며, 자신 사격 생존 보너스가 있다면 해당 금액도 획득 예정 상금에 포함된다.

### 6.8 계속 도전

* 플레이어가 계속 도전을 선택하면 새로운 적이 등장한다.
* 리볼버의 총알 위치와 현재 약실을 다시 설정한다.
* 연속 승리 횟수와 획득 예정 상금은 유지된다.
* 플레이어부터 다시 행동한다.
* 등장하는 적의 수에는 제한이 없다.

### 6.9 상금 수령

* 플레이어가 상금 수령을 선택하면 현재까지 쌓은 획득 예정 상금을 최종 상금으로 확정한다.
* 현재 연속 승리 횟수와 최종 상금을 출력한다.
* 상금을 수령하면 게임이 종료된다.

### 6.10 게임 종료

게임은 다음 두 가지 경우에 종료된다.

* 플레이어가 적을 처치한 후 상금 수령을 선택한 경우
* 러시안 룰렛 도중 플레이어가 사망한 경우

상금을 수령하고 종료한 경우에는 연속 승리 횟수와 최종 상금을 출력한다.

플레이어가 사망한 경우에는 연속 승리 횟수와 잃은 상금을 출력한다.

## 7. 게임 진행 흐름

### 7.1 전체 진행

```text
게임 시작
→ 첫 번째 적 등장
→ 리볼버 준비
→ 플레이어와 적의 대결
→ 적 처치 또는 플레이어 사망
```

적을 처치하면 상금과 연속 승리가 증가한다. 이후 플레이어는 다음 적에게 도전하거나 현재까지 획득한 상금을 받고 게임을 종료할 수 있다.

플레이어가 사망하면 획득 예정 상금을 모두 잃고 게임이 종료된다.

### 7.2 플레이어 차례

플레이어는 남은 약실 수를 확인한 뒤 자신 또는 적에게 사격한다.

| 사격 대상 | 빈 약실               | 총알      |
| ----- | ------------------ | ------- |
| 자신    | 보너스 50원 획득 후 차례 유지 | 플레이어 사망 |
| 적     | 적에게 차례 이동          | 적 처치    |

자신에게 사격해 생존하면 같은 차례에 다시 사격 대상을 선택할 수 있다.

적에게 사격했을 때 빈 약실이면 플레이어의 차례가 끝나고 적의 차례로 넘어간다.

### 7.3 적 차례

적은 자신의 차례가 되면 플레이어에게 사격한다.

| 사격 결과 | 처리              |
| ----- | --------------- |
| 빈 약실  | 플레이어에게 차례 이동    |
| 총알    | 플레이어 사망 및 게임 종료 |

### 7.4 적 처치 후

```text
적 처치
-> 연속 승리 증가
-> 처치 보상 획득
-> 계속 도전 또는 상금 수령 선택
```

* 계속 도전하면 새로운 적이 등장하고 리볼버를 다시 준비한다.
* 연속 승리와 획득 예정 상금은 다음 대결에도 유지된다.
* 상금 수령을 선택하면 최종 기록과 상금을 출력하고 게임을 종료한다.
