# 게임 개요

**- 플레이어와 상대가 공격과 방어를 반복하는 참참참 방식의 게임**

**- 공격자와 방어자가 각각 위 / 아래 / 왼쪽 / 오른쪽 중 하나의 방향을 선택한다.**

**- 공격자와 방어자의 방향이 같으면 공격에 성공한다.**

**- 공격에 성공하면 공격자가 공격권을 유지하여 한 턴 더 공격한다.**

**- 공격자와 방어자의 방향이 다르면 방어에 성공하며 공격권이 상대에게 넘어간다.**

**- 플레이어는 최대 3개의 라이프를 가지고 게임을 시작한다.**

**- 상대의 공격을 피하지 못할 경우 라이프를 잃으며, 라이프가 모두 소진되면 게임 오버된다.**

**- 공격권을 유지하며 연속으로 공격에 성공하는 것이 높은 점수를 얻는 핵심이다.**

---

# 게임 목적

**- 상대가 선택할 방향을 예측하여 공격에 성공한다.**

**- 공격에 성공하여 공격권을 계속 유지한다.**

**- 상대의 공격 방향을 예측하여 공격을 피한다.**

**- 라이프를 최대한 보존하면서 높은 콤보와 점수를 달성한다.**

# 게임 규칙

**- 게임 시작 시 플레이어의 라이프는 3개이다.**

**- 게임은 플레이어의 공격 턴부터 시작한다.**

**- 공격자와 방어자는 각각 하나의 방향을 선택한다.**

**- 선택 가능한 방향은 위 / 아래 / 왼쪽 / 오른쪽이다.**

**- 공격자와 방어자의 방향이 같으면 공격 성공이다.**

**- 공격 성공 시 공격자가 공격권을 유지한다.**

**- 공격 성공 후 다음 턴에도 같은 공격자가 다시 공격한다.**

**- 공격자와 방어자의 방향이 다르면 방어 성공이다.**

**- 방어 성공 시 공격권이 상대에게 넘어간다.**

**- 상대의 공격 방향과 플레이어의 방향이 같으면 플레이어가 공격받아 라이프가 1 감소한다.**

**- 플레이어가 공격에 성공하면 점수를 획득한다.**

**- 플레이어의 라이프가 0이 되면 게임 오버된다.**

# 참참참 판정

### 공격 성공

**공격자와 방어자가 같은 방향을 선택했을 경우**

> 공격자 : →
> 방어자 : →
> **→ 공격 성공**

**- 공격 성공 시 공격자는 공격권을 유지한다.**

**- 다음 턴에도 같은 공격자가 다시 공격한다.**

### 방어 성공

**공격자와 방어자가 다른 방향을 선택했을 경우**

> 공격자 : →
> 방어자 : ↑
> **→ 방어 성공**

**- 방어 성공 시 공격권이 방어자에게 넘어간다.**

**- 다음 턴부터 방어자가 새로운 공격자가 된다.**

---

# 공수 교대 시스템

게임은 **공격 성공 시 공격권 유지 / 방어 성공 시 공격권 교대** 방식으로 진행된다.

### 1. 플레이어 공격 턴

**- 플레이어가 공격자가 된다.**

**- 플레이어가 방향을 선택한다.**

**- 상대가 방어 방향을 선택한다.**

**- 두 방향을 비교하여 결과를 판정한다.**

**- 방향이 같으면 플레이어의 공격 성공**

**→ 플레이어가 공격권 유지**

**→ 플레이어가 한 턴 더 공격**

**- 방향이 다르면 상대의 방어 성공**

**→ 공격권 교대**

**→ 상대가 다음 공격자가 됨**

---

### 2. 상대 공격 턴

**- 상대가 공격자가 된다.**

**- 상대가 방향을 선택한다.**

**- 플레이어가 방어 방향을 선택한다.**

**- 두 방향을 비교하여 결과를 판정한다.**

**- 방향이 같으면 상대의 공격 성공**

**→ 플레이어 라이프 -1**

**→ 상대가 공격권 유지**

**→ 상대가 한 턴 더 공격**

**- 방향이 다르면 플레이어의 방어 성공**

**→ 공격권 교대**

**→ 플레이어가 다음 공격자가 됨**

---

# 공격 콤보

**- 공격에 연속으로 성공하면 공격 콤보가 증가한다.**

**- 공격 콤보는 공격권을 유지한 횟수를 나타낸다.**

**- 공격에 실패하여 상대가 방어에 성공하면 공격 콤보가 초기화된다.**

예시:

> 플레이어 공격 → 성공 → **1 COMBO**
> 플레이어 공격 → 성공 → **2 COMBO**
> 플레이어 공격 → 성공 → **3 COMBO**
> 플레이어 공격 → 성공 → **4 COMBO**
> 플레이어 공격 → 실패 → **공격권 교대 / COMBO 초기화**

**- 공격 콤보가 높을수록 추가 점수를 획득한다.**

# 라이프 시스템

**- 플레이어의 최대 라이프는 3개이다.**

**- 게임 시작 시 3개의 라이프를 가지고 시작한다.**

**- 상대의 공격 방향과 플레이어의 방향이 같으면 라이프가 1 감소한다.**

**- 라이프는 기본적으로 게임 중 회복되지 않는다.**

**- 라이프가 0이 되면 게임 오버된다.**

# 점수 시스템

| 행동       |     점수 |
| -------- | -----: |
| 공격 성공    |   +100 |
| 공격 방어 성공 |   +100 |
| 공격 콤보    | 보너스 점수 |

**- 플레이어가 공격에 성공하면 점수를 획득한다.**

**- 상대의 공격을 성공적으로 방어해도 점수를 획득한다.**

**- 공격에 연속으로 성공할 경우 콤보 보너스를 획득한다.**

**- 게임 종료 시 최종 점수를 표시한다.**

---

# 콤보 시스템

**- 플레이어가 공격에 성공하면 공격 콤보가 1 증가한다.**

**- 공격 콤보가 유지되는 동안 추가 점수를 획득한다.**

**- 플레이어가 공격에 실패하고 상대가 방어에 성공하면 공격 콤보가 초기화된다.**

예시:

**1 COMBO → +100**

**2 COMBO → +100 + 보너스**

**3 COMBO → +100 + 보너스**

**5 COMBO → +100 + 높은 보너스**

**10 COMBO → +100 + 최고 보너스**

# 게임 시작 조건

**- 게임 실행 후 START 버튼을 누르면 게임이 시작된다.**

**- 플레이어 라이프는 3개로 시작한다.**

**- 점수는 0으로 시작한다.**

**- 공격 콤보는 0으로 시작한다.**

**- 플레이어가 첫 번째 공격자가 되어 게임을 시작한다.**

# 게임 종료 조건

**- 게임 오버 시 최종 점수와 최고 공격 콤보를 표시한다.**

**- RESTART 버튼을 통해 게임을 다시 시작할 수 있다.**
