# 아스트랄 아트리에

## 게임 개요  
- 마법진을 직접 그려 발동된 마법으로 적을 쓰러트리는 턴제 게임  

## 게임 목적  
- 세계 최고의 마법사 육성 기관 아스트랄 아트리에에 입학한 당신! 던전에서 마법을 수련해 학파 수석을 노려보세요!

## 조작방법
- 마우스 클릭으로 메뉴, 선택지, 사용할 마법을 선택
- 드래그로 순서대로 마법진 그리기 ( 예시 파이어볼 = 큰 원 > 별 > 작은 원 )

##게임 규칙
 - 플레이어와 적은 일반적인 상황에서 한번씩 번갈아가며 행동한다.
 - 플레이어의 턴에는 사용할 마법을 골라야한다.
 - 마법진은 가장 외곽에서부터 간단한 도형의 형태로 제시된다
 - 마법진 그리기가 시작되고 나서 시간이 기록되며 일정시간 마다 마법의 효과가 감소한다 ( 공격 마법 = 데미지 감소, 수비마법 = 데미지 경감량 감소, 강화마법 = 버프량감소 )

## 점수 / 승부 규칙
- 각 전투에서 플레이어 적은 고유한 hp를 가진다.
- 둘 중 하나의 hp가 고갈되면 전투가 끝이나게 된다.
- 플레이어의 승리시 사용한 턴에 반비례하여 학점을 획득한다

## 게임 시작 조건
- 마법 학파를 선택한 후 던전에 진입

##게임 종료 조건
- 적과의 전투중 플레이어의 체력이 소진될 경우
- 일정 수치의 학점을 충족 했을 경우

## 플레이어 행동
- 학파 선택
- 던전 선택
- 패턴 그리기

## 적 행동
- 전투 시 자신의 턴에 공격 / 수비 둘 중 하나 선택해 사용

##게임 화면
- 왼쪽 상단 : 적
- 화면 중앙 : 플레이어
- 왼쪽 하단 & 중앙 하단 : 마법목록
- 오른쪽 전체 : 패턴 입력 영역

## 게임 진행 흐름
- 아카데미 -> 학파(속성)선택 -> 던전입장 -> 적 조우 -> 전투 -> 결과 확인 -> 다음 던전

## 주요 게임 오브젝트 목록
- 플레이어, 적, 스킬, 마법진

## 필요한 이미지 목록
- 주인공 이미지
- 적 이미지
- 던전, 아카데미 내부 이미지
- 마법 아이콘
- 마법진 이미지
- 마법진 가이드 도형 이미지
