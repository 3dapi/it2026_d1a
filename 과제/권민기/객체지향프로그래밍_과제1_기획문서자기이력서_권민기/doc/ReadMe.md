\## 게임 개요



\### 1. 게임 콘셉트



\* 다가오는 몬스터들을 처치하며 생존하는 종스크롤 탑다운 슈팅 게임



\### 2. 승리 / 패배 조건



\* \*\*승리 조건\*\*: 몬스터를 피하거나 총으로 처치하며 \*\*5분간 생존\*\*

\* \*\*패배 조건\*\*: 몬스터와 \*\*5회 충돌\*\* 시 게임 오버



\### 3. 핵심 시스템 및 조작



\* \*\*자동 전진\*\*: 전투기는 자동으로 전진합니다.

\* \*\*피해 및 종료 시스템\*\*: 몬스터와 5번 충돌하면 게임이 즉시 종료됩니다.

\* \*\*조작 방식\*\*: 방향키 4개 (상, 하, 좌, 우)



\### 4. 필요 리소스 목록



\* \*\*이미지 (그래픽)\*\*

\* 전투기 (플레이어)

\* 몬스터 (적)

\* 게임 종료 후 총점수를 표시하는 점수판 UI
