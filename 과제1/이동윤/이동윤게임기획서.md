# 카우보이 퀵샷

## 게임 소개

* 화면 양쪽에서 갑자기 나타나는 과녁을 빠르게 조준하고 사격하는 순발력 게임
* 단순히 과녁을 클릭하는 것이 아니라 총의 조준선을 직접 움직여 과녁과 맞춘 후 발사해야 한다.

## 게임 목표

* 제한 시간 동안 나타나는 과녁을 최대한 빠르고 정확하게 맞혀 높은 점수를 획득한다.
* 과녁이 등장한 뒤 조준하고 명중시키기까지 걸린 시간이 짧을수록 높은 점수를 얻는다.

## 기본 조작

* 마우스 좌우 이동 : 총과 조준선 이동
* 마우스 왼쪽 클릭 : 총 발사
* 화면 아래의 총은 마우스의 움직임에 따라 좌우로 회전하거나 이동한다.
* 총의 조준선과 과녁이 겹친 상태에서 발사하면 명중한다.

## 게임 규칙

* 게임을 시작하면 잠시 후 화면의 왼쪽 또는 오른쪽에서 과녁이 랜덤하게 등장한다.
* 과녁이 등장하는 위치와 등장까지 걸리는 시간은 매번 달라진다.
* 플레이어는 마우스를 좌우로 움직여 조준선을 과녁에 맞춰야 한다.
* 조준선이 과녁에 닿은 상태에서 마우스를 클릭하면 과녁을 맞힐 수 있다.
* 과녁을 맞히거나 일정 시간이 지나면 해당 과녁은 사라지고 새로운 과녁이 등장한다.
* 과녁이 없는 곳에 총을 발사하면 빗나간 것으로 처리한다.
* 게임이 진행될수록 과녁이 화면에 머무르는 시간이 조금씩 짧아진다.

## 점수 계산

* 과녁 명중 시 기본 점수를 획득한다.
* 과녁 등장 후 빠르게 명중시킬수록 추가 점수를 획득한다.
* 연속으로 과녁을 맞히면 연속 명중 횟수가 증가한다.
* 총알을 빗맞히거나 과녁을 놓치면 연속 명중 기록이 초기화된다.
* 게임 종료 시 명중한 과녁 수와 반응속도를 이용해 최종 점수를 표시한다.

## 게임 진행

1. 시작 버튼을 눌러 게임을 시작한다.
2. 플레이어는 화면 중앙 아래의 총을 조작한다.
3. 잠시 기다리면 왼쪽 또는 오른쪽에서 과녁이 등장한다.
4. 마우스를 움직여 조준선을 과녁 방향으로 맞춘다.
5. 조준이 완료되면 마우스를 클릭해 총을 발사한다.
6. 명중 여부와 획득 점수를 표시한다.
7. 새로운 과녁이 랜덤한 위치에서 등장한다.
8. 제한 시간이 끝날 때까지 반복한다.
9. 게임 종료 후 최종 점수와 명중률을 확인한다.

## 화면 구성

* 화면 중앙 하단 : 플레이어가 사용하는 총
* 총 위쪽 : 현재 총이 향하고 있는 방향을 보여주는 조준선
* 화면 왼쪽 / 오른쪽 : 과녁이 랜덤하게 등장하는 영역
* 화면 상단 : 남은 시간과 현재 점수
* 화면 한쪽 : 연속 명중 횟수
* 게임 종료 화면 : 최종 점수, 명중률, 다시하기 버튼

## 주요 오브젝트

* **총** : 플레이어가 마우스로 조작하며 클릭하면 총알을 발사한다.
* **조준선** : 총이 현재 어느 방향을 조준하고 있는지 보여준다.
* **과녁** : 화면의 좌우에서 랜덤하게 등장하며 플레이어가 맞혀야 하는 대상이다.
* **총알** : 클릭 시 발사되며 조준선과 과녁의 위치를 기준으로 명중 여부를 판단한다.

## 게임 시작 / 종료

* 시작 버튼을 클릭하면 일정 시간 후 첫 번째 과녁이 등장한다.
* 정해진 제한 시간이 모두 지나면 게임이 종료된다.
* 게임 종료 후 최종 점수와 명중률을 보여주고 다시 시작할 수 있다.
