##기획의도: 자투리 시간에 짧고 강렬하게 즐기는 토너먼트 방식의 묵찌빠 대전 게임

##시놉시스: 묵찌빠로 유학까지 다녀온 당신! 이제 묵찌빠 올림픽에서 금매달을 목에 걸기까지 단, 한 걸음
	남았는데요! 당신 앞의 경쟁자를 이겨 눈물 콧물 싹 다 빼주시죠!

##핵심시스템 : 8강전의 토너먼트 방식으로 진행
- 1라운드. 선공 결정 : 일반 가위바위보 규칙으로 첫 공격권을 정한다.(가위 > 보 > 바위 > 가위)
- 1라운드 -1. 비길 경우 서로다른패가 나올떄까지 진행한다. 이때 서로 다른 패가 나올 때까지 계속 
			1라운드가 끝나지 않은 것으로 취급한다.
			
- 2라운드~. 묵찌빠 진행 : 공경권을 쥔상태에서 상대방과 같은 패를 내면 세트 1점 획득
- 2라운드~ -1.패가 다르고 상성상 이기게 되면 공격권을 유지한 채 다음 라운드를 진행한다. 패가
			다르고 상성상 졌다면 공격권을 넘겨주고 다음라운드를 진행한다.
			
- 세트 승리조건 : 먼저 2세트를 따내는 쪽이 해당경기의 승자가 되어 다음 토너먼트 라운드에 진출한다.

##토너먼트 진행 구조
- 경기 방식 : 모든 라운드 3판 2선승제(2세트 선승 시 승리) 고정
- 대진표 흐름 : 8강전 > 4강전 > 결승전 > 최종 우승(금메달 획득)
- 경기 진행 : 각 경기 승리 시 다음 라운드 진출 / 패배 시 즉시 게임 오버 (재도전 가능)

##전체게임 플로우
- 1. 게임 시작: 메인 화면에서 게임 시작 클릭 > 8강 토너먼트 대진표 대치
- 2. 매치 진입(8강 / 4강 / 결승)
- 2-1. 1라운드: 마우스로 패 선택 > 선공(공격권) 결정
- 2-2. 2라운드~: 공격/수비 상황에 맞춰 패 선택 > 같은 패 선택 시 세트 득점
- 2-3. 세트 반복: 한 선수가 2점을 얻을 때까지 매치 반복
- 3. 결과 처리 : 승리 시 다음 토너먼트 단계로 이동(8강 > 4강 > 결승), 결승 승리 시 올림픽
			금메달 획득, 패배 시 토너먼트 탈락 (게임 오버 화면과 함께 메인 화면으로 이동)

	단순하게 4강전은 그보다 좀 더 복잡하게 같은 방식으로)
