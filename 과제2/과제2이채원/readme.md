# 스낵 메이즈


## 게임 개요

플레이어가 미로를 돌아다니며 맵에 있는 간식을 획득하는
간단한 2D 게임입니다.

## 기획의도

자투리 시간에 간단하게 즐길 수 있는 미로 탐색 방식의 게임을 제작한다.
플레이어가 미로를 돌아다니며 간식을 획득하고 적을 피해 모든 간식을 모으는 것을 목표로 한다.

## 시놉시스

미로에 흩어진 맛있는 간식들!
미로에 갇힌 플레이어는 간식을 모아 에너지를 충전해야 한다.
플레이어는 미로를 돌아다니며 모든 간식을 찾아야 한다.
하지만 미로에는 플레이어를 방해하는 적이 존재한다.
적을 피해 모든 간식을 획득하고 미로를 탈출하자!

## 핵심시스템

- 플레이어는 방향키를 이용하여 미로 안을 이동한다.
- 미로에는 간식과 적이 배치되어 있다.
- 간식을 획득하면 점수를 얻는다.
- 벽이 있는 곳으로는 이동할 수 없다.
- 적과 충돌하면 게임에서 패배한다.
- 모든 간식을 획득하면 게임에서 승리한다.

## 게임 목표

맵에 존재하는 모든 간식을 획득하면 게임에서 승리합니다.

## 게임 방법

- 방향키를 이용하여 플레이어를 이동합니다.
- 맵에 있는 간식을 획득하면 점수가 증가합니다.
- 적과 부딪히면 게임 오버가 됩니다.
- 모든 간식을 획득하면 게임 클리어입니다.

## 조작 방법

- ↑ : 위로 이동
- ↓ : 아래로 이동
- ← : 왼쪽으로 이동
- → : 오른쪽으로 이동

## 게임 요소

### 플레이어
방향키를 이용하여 맵을 이동합니다.

### 간식
플레이어가 획득하면 점수가 증가합니다.

### 적
맵을 돌아다니며 플레이어를 방해합니다.

### 맵
플레이어가 이동할 수 있는 공간과 벽으로 구성됩니다.

## 승리 조건

맵에 있는 모든 간식을 획득하고 탈출구로 복귀합니다.

## 패배 조건
플레이어가 적과 충돌합니다.
