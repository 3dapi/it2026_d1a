## 1. 게임 개요
다가오는 몬스터들을 피하거나 총으로 처치하며 생존하는 **종스크롤 탑다운 슈팅 게임**입니다.  
전투기는 화면 위쪽을 향해 자동으로 전진하며, 플레이어는 좌우상하로 회피 기동을 하면서 자동으로 발사되는 총알로 몬스터를 처치합니다.

## 2. 게임 목적
**5분간 생존**하면서 몬스터를 처치해 최대한 높은 점수를 획득하는 것이 목표입니다.

## 3. 조작 방법
| 구분 | 입력 방식 | 설명 |
| :--- | :--- | :--- |
| **이동** | 방향키 (`↑`, `↓`, `←`, `→`) | 전투기를 상하좌우로 이동 |
| **공격** | 자동 발사 | 별도 입력 없이 일정 주기로 총알 발사 (조작 단순화) |

## 4. 게임 규칙
* **자동 전진 연출:** 전투기는 화면 안에서 자동으로 앞으로 나아가는 연출을 갖습니다 (배경 스크롤로 표현).
* **웨이브 시스템:** 몬스터는 정해진 패턴(웨이브) 형태로 화면 위쪽에서 아래로 내려옵니다.
* **HP(생명력) 시스템:** 
  * 5칸에서 시작하며, 몬스터와 충돌할 때마다 1칸씩 감소합니다.
  * HP가 0이 되면 즉시 **게임 오버(패배)**로 처리됩니다.
* **무적 시간:** 충돌 즉시 연속으로 HP가 깎이지 않도록 충돌 후 짧은 무적 시간(예: 1초)을 부여합니다.
* **아이템:** 아이템은 사용하지 않습니다 (순수 슈팅 + 회피 스코프).

## 5. 점수 / 승부 규칙
* **몬스터 처치 점수:** 몬스터 처치 시 고정 점수 획득 (예: 1마리 처치당 10점)
* **생존 시간 점수:** 생존 시간에 비례한 점수 누적 (예: 1초 생존당 1점)
* **최종 점수:** $\text{처치 점수 합계} + \text{생존 시간 점수}$
* 게임 종료 시 최종 점수를 점수판 UI에 표시합니다.

## 6. 게임 시작 조건
프로그램 실행 후 타이틀 화면이 표시되며, 시작 입력(예: `Spacebar` 또는 `Enter`) 시 플레이 화면으로 전환되어 게임이 시작됩니다.

## 7. 게임 종료 조건
* **승리:** HP를 1칸 이상 남긴 채 **5분간 생존** 성공
* **패배:** HP가 0이 됨 (몬스터와 **5회 충돌**)
> 두 조건 중 하나를 만족하면 즉시 게임이 종료되고 결과(점수) 화면으로 전환됩니다.

## 8. 플레이어 행동
* **이동:** 방향키 입력에 따라 상하좌우로 이동
* **공격:** 자동으로 총알을 일정 주기마다 발사
* **피격:** 몬스터와 충돌 시 HP 1 감소 + 짧은 무적 시간 부여

## 9. 적 / 장애물 / 아이템 행동
* **몬스터 (Monster):**
  * 화면 위쪽에서 정해진 패턴(웨이브)을 따라 하강하며 이동합니다.
  * 플레이어 총알에 맞으면 소멸하고 처치 점수를 지급합니다.
  * 화면 아래 끝까지 도달하거나 플레이어와 충돌하면 소멸합니다.
* **아이템:** 미사용 (해당 없음)

## 10. 게임 화면 구성
1. **상단 HUD:** 현재 점수, 생존 시간, 남은 HP 표시
2. **중앙 플레이 필드:** 전투기, 몬스터, 총알이 배치되는 스크롤 배경 영역
3. **타이틀 화면:** 게임 제목 + 시작 안내 문구
4. **결과 화면:** 승리/패배 여부 + 최종 점수 표시

## 11. 게임 진행 흐름
```text
[타이틀 화면] 
      │ (시작 입력: Space / Enter)
      ▼
[플레이 화면 진입] ─── (이동 / 자동사격 / 충돌판정 반복)
      │
      ├───────────────────────────────┐
      ▼                               ▼
[승리: 5분 생존 성공]            [패배: HP 0 (5회 충돌)]
      │                               │
      └───────────────┬───────────────┘
                      ▼
               [결과 화면] (최종 점수 표시)
                      │
            (재시작 또는 종료 선택)
```

## 12. 주요 게임 객체 목록
* `Player`: 전투기, 이동 및 발사 담당
* `Bullet`: 플레이어가 발사하는 총알
* `Monster`: 웨이브 패턴으로 하강하는 적
* `GameManager`: 생존 시간, 충돌 카운트, 승패 판정 총괄
* `ScoreUI`: 점수/생존시간/충돌 횟수 표시
* `TitleScreen` / `ResultScreen`: 시작 화면과 결과 화면 UI
