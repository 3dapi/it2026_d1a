# 카우보이 슈팅 스타

## 게임 소개

-   화면 양쪽에서 갑자기 나타나는 과녁을 빠르게 조준하고 사격하는 순발력
    게임
-   별도의 조준선 없이 총의 위치와 과녁의 위치를 보고 감으로 조준하여
    발사한다.

## 게임 목표

-   제한 시간 동안 나타나는 과녁을 최대한 빠르고 정확하게 맞혀 높은
    점수를 획득한다.
-   과녁이 등장한 뒤 빠르게 명중시킬수록 높은 점수를 얻는다.

## 기본 조작

-   마우스 좌우 이동 : 총 이동
-   마우스 왼쪽 클릭 : 총 발사
-   화면 아래의 총은 마우스의 움직임에 따라 좌우로 이동한다.
-   조준선이 표시되지 않기 때문에 총이 향하는 위치를 보고 직접 과녁을
    조준해야 한다.

## 게임 규칙

-   게임을 시작하면 잠시 후 화면의 왼쪽 또는 오른쪽에서 과녁이 랜덤하게
    등장한다.
-   과녁이 등장하는 위치와 등장까지 걸리는 시간은 매번 달라진다.
-   플레이어는 마우스를 좌우로 움직여 총을 과녁 방향으로 맞춘다.
-   마우스 왼쪽 버튼을 클릭하면 총을 발사한다.
-   과녁을 명중시키면 과녁 이미지가 부서진 과녁 이미지로 변경된 후
    사라진다.
-   과녁을 맞히거나 일정 시간이 지나면 새로운 과녁이 등장한다.
-   과녁이 없는 위치에 발사하면 빗나간 것으로 처리한다.
-   게임이 진행될수록 과녁이 화면에 머무르는 시간이 조금씩 짧아진다.

## 점수 계산

-   과녁을 명중시키면 기본 점수를 획득한다.
-   과녁이 등장한 후 빠르게 명중시킬수록 추가 점수를 획득한다.
-   제한 시간이 끝나면 획득한 점수를 합산하여 최종 점수를 표시한다.

## 게임 진행

1.  시작하기 버튼을 눌러 게임을 시작한다.
2.  화면 중앙 하단에 총이 나타난다.
3.  잠시 기다리면 화면의 왼쪽 또는 오른쪽에 과녁이 등장한다.
4.  마우스를 좌우로 움직여 총을 과녁 방향으로 조준한다.
5.  마우스 왼쪽 버튼을 클릭해 총을 발사한다.
6.  명중하면 과녁이 부서지는 이미지로 변경되고 점수를 획득한다.
7.  잠시 후 새로운 과녁이 랜덤한 위치에 등장한다.
8.  제한 시간이 끝날 때까지 과정을 반복한다.
9.  게임 종료 후 최종 점수를 확인한다.

## 화면 구성

-   화면 상단 중앙 : 게임 제목
-   화면 상단 : 남은 시간과 현재 점수
-   화면 중앙 하단 : 플레이어가 사용하는 총
-   화면 왼쪽 / 오른쪽 : 과녁이 랜덤하게 등장하는 영역
-   게임 종료 화면 : 최종 점수와 다시하기 버튼

## 주요 오브젝트

-   **총** : 마우스 좌우 이동에 따라 움직이며 클릭하면 발사한다.
-   **과녁** : 화면 좌우의 랜덤한 위치에 등장하는 목표물이다.
-   **부서지는 과녁** : 과녁 명중 시 기존 과녁을 대신하여 잠시 표시된다.
-   **발사 이펙트** : 총을 발사했을 때 총구에 표시되는 효과이다.
-   **제목** : 게임 시작 화면에 표시되는 카우보이 슈팅 스타 제목이다.
-   **시작하기** : 게임을 시작하는 버튼이다.
-   **다시하기** : 게임 종료 후 게임을 처음부터 다시 시작하는 버튼이다.

## 게임 시작 / 종료

-   시작하기 버튼을 클릭하면 게임이 시작되고 일정 시간 후 첫 번째 과녁이
    등장한다.
-   정해진 제한 시간이 모두 지나면 게임이 종료된다.
-   게임 종료 후 최종 점수를 표시하며 다시하기 버튼으로 게임을 재시작할
    수 있다.

## 필요한 이미지 및 사운드

### 이미지

-   총
-   과녁
-   부서지는 과녁
-   발사 이펙트
-   제목
-   시작하기 버튼
-   다시하기 버튼
-   서부 사막 또는 마을 배경

### 사운드

-   서부 분위기의 배경음
-   총 발사음
-   과녁 명중음
-   빗나갔을 때 효과음
-   게임 시작 / 종료 효과음
