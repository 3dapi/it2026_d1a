# ONE TORCH — 핵심 게임 기획서

> 횃불 하나로 몰려오는 괴물들을 밀쳐내고, 포위망의 틈을 지나 단 1초라도 더 살아남아라.

## 1. 게임 개요

| 항목 | 기획 |
|---|---|
| 제목 | ONE TORCH |
| 장르 | 2D 탑뷰 무한 생존 액션 |
| 형식 | 한 화면에서 짧게 도전하고 즉시 재시작하는 플래시게임 감성 |
| 공간 | 장애물 없는 작은 원형 맵, 고정 카메라 |
| 목표 | 불씨가 꺼지기 전까지 최대한 오래 생존 |
| 종료 조건 | 불씨 게이지 0 |
| 기록 | 생존 시간과 개인 최고 기록 |
| 기본 조작안 | WASD 이동, 마우스로 방향 지정, 왼쪽 클릭으로 횃불 휘두르기 |

제한시간과 최종 클리어는 없다. 시간이 쌓일수록 압박이 커지고, 플레이어는 이전 기록을 넘어서는 것을 목표로 삼는다. 아래 세부 규칙과 수치는 첫 프로토타입을 위한 설계 제안이며 플레이테스트로 조정한다.

## 2. 핵심 컨셉과 의도한 경험

**작은 불빛 하나에 의지해, 압도적인 무리 사이에서 스스로 탈출할 틈을 만드는 생존.**

플레이어에게 주고 싶은 감정은 “강해져서 모두 쓰러뜨렸다”보다 “방금 정말 죽을 뻔했는데 내가 길을 만들어 살아났다”에 가깝다. 어둠과 괴물은 압박을, 횃불은 상황을 바꿀 수 있다는 희망을 담당한다.

ONE TORCH의 중심은 **밀쳐내기로 잠깐의 안전 공간을 만드는 것**이다. 횃불은 적을 제거하지 않는다. 적의 위치를 바꾸고 접근을 잠시 늦춰, 플레이어가 이동할 시간과 공간을 만든다. 그 공간은 곧 다시 메워지므로 계속 다음 길을 판단해야 한다.

‘불씨’는 남은 생존 여력을 뜻한다. 꺼질 수 있으며, 꺼지면 게임이 끝난다.

## 3. 핵심 재미를 구현하는 설계

| 핵심 재미 | 구현 규칙 | 플레이어의 판단 | 기대하는 감정 |
|---|---|---|---|
| 포위망을 뚫는 쾌감 | 횃불이 전방 부채꼴 범위의 여러 적을 동시에 밀어냄 | 어느 방향을 밀어야 빠져나갈 수 있을까? | 내가 출구를 만들었다 |
| 아슬아슬한 회피 | 적은 계속 추적하고, 밀린 적도 다시 접근 | 열린 틈으로 지금 들어갈까, 바깥으로 돌아갈까? | 간발의 차로 피했다 |
| 위험을 감수하는 선택 | 장작은 직접 접근해 주워야 회복 가능 | 지금 회복하러 갈까, 먼저 적을 다른 곳으로 유인할까? | 위험했지만 살아날 기회를 얻었다 |
| 성장하는 실력의 체감 | 생존 시간·최고 기록 표시, 즉시 재시작 | 지난번 막혔던 상황을 어떻게 넘길까? | 이번에는 더 버틸 수 있다 |

이 네 가지는 하나의 흐름으로 연결된다. 장작을 향한 이동이 적의 배치를 바꾸고, 바뀐 배치가 다음 횃불 사용 방향을 결정하며, 성공적인 탈출이 더 높은 기록으로 이어진다.

## 4. 핵심 재미의 연쇄 반응

### 4-1. 기본 생존 순환

**적 접근 → 이동 가능한 공간 감소 → 밀쳐낼 방향 선택 → 횃불 사용 → 일시적인 틈 생성 → 틈으로 이동 → 적 재접근**

1. 괴물이 여러 방향에서 접근하며 이동 경로를 좁힌다.
2. 플레이어는 가장 가까운 적뿐 아니라, 밀어낸 뒤 자신이 이동할 위치를 함께 본다.
3. 적 여러 마리를 한 방향으로 밀어내며 통로를 만든다.
4. 그 틈이 닫히기 전에 이동하면 포위에서 벗어난다.
5. 밀려난 적은 사라지지 않고 다시 접근한다. 다른 방향의 적과 합쳐지며 새로운 포위 형태가 생긴다.

횃불의 보상은 처치 점수가 아니라 **실제로 통과할 수 있는 빈 공간**이다. 넉백 연출만 크고 플레이어가 빠져나갈 수 없다면 핵심 재미가 성립하지 않는다.

### 4-2. 장작이 만드는 위험과 회복의 순환

**피격 → 불씨 감소 → 장작 필요 → 이동 경로 변경 → 적 배치 변화 → 밀쳐내기와 회피 → 장작 획득 → 생존 연장**

장작은 계속 같은 방향으로 도는 플레이를 흔든다. 안전한 경로를 유지할지, 위험한 경로로 가서 회복할지 선택하게 한다. 장작을 먼저 먹기 어렵다면 반대편으로 적을 유인한 뒤 돌아오는 방법도 가능하다.

회복은 판을 초기화하지 않는다. 불씨는 회복되지만 시간과 적의 압박은 유지되므로, 회복 직후에도 다음 탈출 경로를 찾아야 한다.

### 4-3. 기록과 재도전의 순환

**생존 시간 증가 → 압박 증가 → 판단 실수 → 종료 → 이전 기록과 비교 → 실패 원인을 떠올림 → 즉시 재도전**

플레이어가 “횃불을 너무 일찍 썼다”, “장작을 보느라 뒤쪽 적을 놓쳤다”처럼 실패 원인을 이해할 수 있어야 한다. 다음 시도에서 행동을 바꿀 여지가 재도전 의욕을 만든다. 첫 버전에는 영구 능력치 강화를 넣지 않아, 기록 상승이 조작과 판단의 향상으로 느껴지게 한다.

## 5. 핵심 시스템 규칙

### 이동과 공간

- 한 화면 안의 원형 맵에서 자유롭게 이동한다. 맵 가장자리 밖으로는 나갈 수 없다.
- 장애물 없이 시작해 적의 위치와 밀쳐내기가 경로를 결정하게 한다.
- 기본 적은 플레이어보다 느리게 설정한다. 이동으로 피할 여지를 주되, 여러 방향의 접근으로 경로 선택을 요구한다.
- 적끼리 완전히 겹쳐 한 덩어리가 되지 않도록 간단한 간격 유지 처리를 적용한다.

### 횃불 휘두르기

- 마우스가 가리키는 방향의 가까운 부채꼴 범위를 공격한다.
- 범위 안의 적을 플레이어 반대 방향으로 밀고 잠깐 멈추게 한다. 적은 죽지 않는다.
- 휘두른 뒤 짧은 재사용 대기시간을 둬 사용 방향과 시점에 의미를 준다.
- 첫 버전에서는 사용 시 불씨를 소모하지 않는다. 방향·타이밍·재사용 대기만으로 판단이 생기는지 먼저 확인한다.
- 공격 중에도 이동할 수 있어야 하며, 횃불 효과와 실제 판정 범위가 일치해야 한다.

### 불씨와 피격

- 불씨 게이지가 체력을 대신한다. 적과 접촉하면 감소하고 0이 되면 종료한다.
- 첫 버전에서는 시간 경과만으로 불씨가 감소하지 않는다. 생존 압박은 적의 접근에서 발생한다.
- 피격 직후 짧은 무적 시간을 둬, 여러 적과 접촉했다고 한순간에 모든 불씨를 잃지 않게 한다.
- 불씨가 줄면 불꽃의 크기와 소리를 변화시키되, 적을 읽을 수 있는 최소 시야는 유지한다. 첫 버전에서는 시야 범위를 고정한다.

### 장작

- 일정 간격으로 맵의 유효한 바닥에 생성되고, 닿으면 불씨를 회복한다.
- 최대 불씨를 초과해 회복하지 않는다. 불씨가 가득 찼을 때는 장작을 자동 소비하지 않는다.
- 플레이어 바로 아래나 적 몸체와 겹치는 위치는 생성 후보에서 제외한다.
- 위치는 은은한 빛으로 확인할 수 있게 한다. 먼 거리 자체보다 접근 경로에 있는 적이 위험을 만들게 한다.
- 장작의 동시 존재 수를 제한해 회복 자원이 무한히 쌓이지 않게 한다.

## 6. 시간에 따른 난이도 설계

난이도는 적을 더 많이, 더 빠르게 만드는 것뿐 아니라 **안전한 경로를 찾고 이용할 여유가 줄어드는 과정**으로 설계한다. 다음 시간대는 목표 경험의 예시다.

| 생존 시간 | 압박 변화 | 플레이어에게 요구하는 행동 |
|---|---|---|
| 0~30초 | 느린 기본 적이 드물게 등장 | 이동과 밀쳐내기의 관계 익히기 |
| 30~90초 | 등장 간격 감소, 여러 방향에서 접근 | 탈출할 방향을 정하고 밀어내기 |
| 90~180초 | 확장 버전에서 예고 후 돌진하는 적 추가 | 현재 경로와 잠시 후 위험을 함께 보기 |
| 180초 이후 | 확장 버전에서 넉백 저항이 큰 적을 소수 추가 | 밀어낼 무리와 돌아갈 적 구분하기 |
| 장기 생존 | 설정된 상한 안에서 혼합 패턴과 압박 지속 | 좁은 여유를 활용해 기록 갱신하기 |

첫 프로토타입은 기본 적 한 종류와 생성 간격 변화만 사용한다. 적 종류와 속도를 동시에 늘리면 무엇 때문에 어려워졌는지 판단하기 어려우므로 단계적으로 추가한다.

**제한시간이 없다는 것과 적 수·속도가 무한히 커진다는 것은 다르다.** 적을 없앨 수 없는 작은 맵에서는 적이 무한히 쌓이면 실력과 관계없이 이동 공간이 사라진다. 따라서 동시 적 수와 속도에 상한을 두고, 상한에 도달하면 추가 생성을 멈춘다. 장기 난이도는 상한에 수렴하도록 설계하며 실제로 탈출 가능한 여유가 남는지 검증한다.

## 7. 조작감과 시청각 반응

| 상황 | 피드백 | 기능 |
|---|---|---|
| 횃불 휘두르기 | 짧은 불꽃 궤적과 바람 가르는 소리 | 방향과 범위 전달 |
| 적 밀쳐내기 성공 | 적이 즉시 밀리고 잠깐 움츠러듦 | 통로가 열렸음을 확인 |
| 재사용 가능 | 횃불 옆 작은 표시가 다시 밝아짐 | 다음 행동 가능 시점 전달 |
| 피격 | 캐릭터 점멸, 불꽃 약화, 짧은 효과음 | 위험과 무적 상태 전달 |
| 장작 획득 | 불꽃이 살아나고 게이지 상승 | 회복 성공과 안도감 전달 |
| 최고 기록 돌파 | 작은 문구와 짧은 소리 | 플레이를 가리지 않고 성취 전달 |
| 불씨 소진 | 불꽃 소멸 후 결과 표시 | 생존 종료를 명확히 전달 |

어둠은 분위기를 만들되 위험 정보를 숨기는 데 의존하지 않는다. 적의 윤곽과 돌진 예고는 식별 가능해야 한다. 흔들림과 불꽃 효과도 이동 경로를 가리지 않을 정도로 제한한다.
