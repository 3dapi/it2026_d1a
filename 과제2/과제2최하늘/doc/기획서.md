# Ten Planets

## 1. 게임 설명

우주 공간에 숫자가 적힌 여러 행성이 나타난다.

플레이어는 마우스 왼쪽 버튼을 누른 상태로 드래그하여
여러 개의 행성을 선택할 수 있다.

선택한 행성에 적힌 숫자를 모두 더했을 때
합이 10이 되면 선택한 행성들이 소멸한다.

합이 10이 아니라면 행성은 사라지지 않고 그대로 유지된다.

행성이 소멸하면 새로운 행성이 생성된다.

제한시간 동안 최대한 많은 행성을 소멸시켜
높은 점수를 획득하는 것이 목표이다.


## 2. 게임 규칙

### 성공 예시

3 + 7 = 10
→ 행성 소멸

2 + 3 + 5 = 10
→ 행성 소멸

1 + 2 + 3 + 4 = 10
→ 행성 소멸


### 실패 예시

4 + 2 + 3 = 9
→ 행성 유지

6 + 7 = 13
→ 행성 유지


## 3. 조작 방법

마우스 왼쪽 클릭 + 드래그

1. 마우스 왼쪽 버튼을 누른다.
2. 드래그하여 여러 행성을 선택한다.
3. 마우스 왼쪽 버튼을 놓는다.
4. 선택된 행성의 숫자를 모두 더한다.
5. 합이 10인지 확인한다.


## 4. 점수

행성을 소멸시키면 점수를 획득한다.

한 번에 많은 행성을 이용하여 10을 만들수록
더 높은 점수를 획득한다.

- 행성 2개 소멸 : 100점
- 행성 3개 소멸 : 200점
- 행성 4개 소멸 : 350점
- 행성 5개 이상 소멸 : 500점


## 5. 기본 게임 진행

↓

# Scene 1. Game Start

게임 시작 화면이다.

화면 중앙에 게임 제목인
"Ten Planets"를 표시한다.

게임 제목 아래에 START 버튼을 배치한다.

START 버튼을 클릭하면
게임 플레이 화면으로 이동한다.

![게임 시작 화면](../resource/tex_ui/scene_start.png)


# Scene 2. Game Play

실제 게임을 플레이하는 화면이다.

화면에 여러 개의 행성을 배치한다.

각 행성에는 1~9 사이의 숫자가 표시된다.

플레이어는 마우스 드래그를 이용하여
여러 개의 행성을 선택한다.

선택한 행성의 숫자 합이 10이면
해당 행성들이 소멸한다.

행성이 소멸하면 점수가 증가하고
새로운 행성이 생성된다.

화면 상단에는 현재 점수와
남은 제한시간을 표시한다.

![게임 플레이 화면](../resource/tex_ui/scene_play.png)


# Scene 3. Game End

제한시간이 0이 되면 게임이 종료된다.

게임 종료 화면에서는
플레이어가 획득한 최종 점수를 표시한다.

RETRY 버튼을 누르면 게임을 다시 시작한다.

EXIT 버튼을 누르면 프로그램을 종료한다.

![게임 종료 화면](../resource/tex_ui/scene_end.png)


## 6. 프로그래밍할 때 참고

- 행성을 화면에 랜덤으로 배치
- 각 행성에 1~9 숫자를 랜덤으로 설정
- 마우스 드래그 영역 확인
- 드래그 영역 안의 행성 선택
- 선택된 행성 숫자 더하기
- 합이 10인지 확인
- 합이 10이면 선택한 행성 삭제
- 삭제된 위치에 새로운 행성 생성
- 제거한 행성 개수에 따라 점수 증가
- 제한시간 설정
- 현재 점수 화면에 표시
- 남은 시간 화면에 표시
- 시간이 0이 되면 게임 종료 화면으로 이동
- 최종 점수 표시
- 다시하기 기능
- 프로그램 종료 기능
